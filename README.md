## About Shred Security

Shred Security provides high quality security audits for blockchain and DeFi protocols across different chains. Our audits consistently uncover high-impact vulnerabilities missed by others, backed by a proven track record of top competition placements and security partnerships with leading protocols.

We also develop open security resources for the broader ecosystem. Our [Protocol Deployment Checklist](https://github.com/Shred-Security/protocol-deployment-checklist) defines baseline deployment-readiness requirements for smart contract protocols, and our [Incident Response Checklist](https://github.com/Shred-Security/Incident-Response-Checklist) provides a structured framework for protocol incident response from alert to safe harbor. [HackViz](https://hackviz.shredsecurity.io) is an interactive platform to learn from, simulate, and visualize past exploits, helping teams build stronger intuition for real-world attack patterns.

Shred Security's mission is to raise the standard of on-chain security through rigorous audits and practical, openly shared security tooling.
